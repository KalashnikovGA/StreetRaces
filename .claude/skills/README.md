# Установленные скиллы

Скиллы из внешних репозиториев, поставленные по запросу владельца проекта.
Лежат в репозитории, потому что сессии запускаются в одноразовых контейнерах:
вне репозитория они не переживут перезапуск.

## Что НЕ установлено и почему

**Хуки AlterLab GameForge** (`hooks/*.sh` в исходном репозитории). Хуки исполняются
автоматически на событиях сессии — старт, компакт, коммит, остановка. Это не инструкции,
а запуск чужого кода без явного вызова, поэтому ставить их без отдельного решения
владельца проекта нельзя. Если понадобятся, ставим отдельно и разбираем построчно.

**Спутники ui-ux-pro-max** (`design`, `design-system`, `brand`, `ui-styling`, `slides`,
`banner-design` из того же репозитория). Имена `design` и `design-system` конфликтуют
с уже существующими скиллами. Сам `ui-ux-pro-max` от них не зависит — ссылается только
на собственные файлы.

**Баннеры README** двух скиллов ParanoiaSkills (4.2 МБ картинок). На них нет ссылок
ни из одного `SKILL.md`.

## Что стоит знать перед использованием

- `game-experience-analyzer` и часть справочников `game-concept-architect` написаны
  по-китайски и выдают отчёты на китайском.
- Скиллы — это инструкции, которые модель исполняет. Перед установкой они проверены
  на попытки переопределить системные правила, обратиться к учётным данным и увести
  данные наружу; ничего такого не найдено. При обновлении из апстрима проверять заново.
